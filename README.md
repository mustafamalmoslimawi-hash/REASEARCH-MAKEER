# 🔬 RESEARCH-MAKER (منصة توليد البحوث العلمية المؤتمتة)

منصة ذكية ومطورة باستخدام **Python** و **Streamlit** تهدف إلى أتمتة عملية البحث العلمي. بمجرد إدخال عنوان البحث، يقوم النظام بالبحث التلقائي عبر محركات البحث الأكاديمية وصياغة بحث كامل يتضمن المقدمة، النتائج، والمراجع بدقة عالية.

---

## ✨ الميزات الأساسية (Features)
* 🔍 **البحث التلقائي المتكامل:** ربط مباشر مع محركات البحث الأكاديمية (مثل Google Scholar) لجلب الأوراق العلمية والملخصات تلقائياً.
* ✍️ **صياغة ذكية للأقسام:** استخدام نماذج الذكاء الاصطناعي (LLMs) لكتابة المقدمة (Introduction) وتحليل النتائج (Results & Discussion).
* 📚 **إدارة مراجع دقيقة:** اقتباس وتوثيق آلي للمراجع المستخدمة داخل النص وفي نهاية البحث بأنظمة مختلفة مثل (APA, IEEE, Harvard).
* 📄 **تصدير التقارير:** إمكانية تحميل البحث النهائي بصيغة ملفات نصية جاهزة للتعديل والأكاديمية.
